
# Responsive Flexbox Layout Using Media Queries

## Description
Created a responsive webpage using HTML and CSS with three child containers displaying Lorem Ipsum paragraph content. Used Flexbox and CSS media queries to adjust the layout according to different screen sizes.

## HTML Concepts Used
- HTML5 document structure
- Viewport meta tag
- Linking external CSS file using `<link>`
- `<div>` elements for container and child sections
- `<p>` tag for paragraph content
- Lorem Ipsum placeholder content

## CSS Concepts Used
- Universal selector (`*`)
- Margin and padding reset
- Box-sizing: border-box
- Border styling
- Height and width properties
- Display: flex
- Flexbox gap property
- Flex-direction: column
- Align-items: center
- Font-size property
- CSS media queries
- Responsive design using different screen breakpoints

## Responsive Breakpoints

| Screen Width | Child Width | Child Height | Font Size |
|---|---:|---:|---:|
| Above 730px | 495px | 110px | 14px |
| 730px and below | 495px | 100px | 14px |
| 515px and below | 395px | 200px | 14px |
| 420px and below | 295px | 300px | 14px |
| 313px and below | 200px | 150px | 8px |

## Features
- Three child containers arranged horizontally on larger screens.
- Flexbox layout used to arrange the child elements.
- Child containers change to a vertical layout on smaller screens.
- Different media queries used to adjust width, height, and font size.
- Responsive layout for desktop, tablet, and mobile screens.

## Technologies Used
- HTML5
- CSS3

## Learning Outcome
Learned how to create a responsive webpage using Flexbox and CSS media queries. Practised changing container alignment, width, height, and font size based on different screen sizes.
